# Client Behavioral Risk Score

## О проекте

Учебный аналитический проект по оценке поведенческого риска клиента на основе истории платежей по кредитной карте.

## Задача

Проверить, позволяет ли платёжное поведение клиента лучше оценивать риск дефолта в следующем месяце, чем использование только базовых характеристик клиента.

## Цель

Построить индивидуальный `Risk Score` для каждого клиента, сравнить качество моделей и выделить группы клиентов с различным уровнем риска.

## Данные

Использован открытый набор **Default of Credit Card Clients** из UCI Machine Learning Repository: 30 000 клиентов и история платежей за шесть месяцев.

Источник: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
