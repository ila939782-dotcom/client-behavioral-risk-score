# Client Behavioral Risk Score

## О проекте

Client Behavioral Risk Score — учебный аналитический проект по оценке риска дефолта клиента на основе его платёжного поведения.

Проект моделирует задачу мониторинга кредитного портфеля: необходимо определить клиентов с повышенным риском проблем с платежами в следующем месяце и сформировать понятный инструмент для их приоритизации.

## Задача

Проверить, насколько информация о фактическом платёжном поведении клиента позволяет точнее оценивать кредитный риск по сравнению с использованием только базовых характеристик клиента.

В рамках анализа рассматриваются:

- история просрочек;
- изменение платёжной дисциплины;
- уровень использования кредитного лимита;
- объём и регулярность платежей;
- базовые характеристики клиента.

## Цель

Построить индивидуальный Risk Score, который:

- оценивает вероятность дефолта клиента;
- позволяет ранжировать клиентов по уровню риска;
- разделяет портфель на риск-группы;
- помогает выделить приоритетную группу клиентов для дополнительной проверки.

## Реализация

В рамках проекта:

1. Подготовлены и структурированы исходные данные по 30 000 клиентам.
2. История платежей преобразована в аналитические признаки на уровне клиента.
3. Проведено сравнение базовой модели и модели с поведенческими признаками.
4. Для каждого клиента рассчитана вероятность дефолта и Risk Score от 0 до 100.
5. Клиенты распределены по риск-группам A–E.
6. Сформирован итоговый Excel-файл для анализа результатов и работы с клиентским портфелем.

## Результат

Анализ показал, что использование истории платёжного поведения позволяет лучше ранжировать клиентов по уровню риска, чем модель, основанная только на базовом профиле клиента.

Итоговый Risk Score используется как единый показатель для сравнения клиентов и формирования приоритетной очереди для дополнительного анализа.

## Данные

Использован открытый набор **Default of Credit Card Clients** из UCI Machine Learning Repository.

Набор содержит данные по 30 000 клиентам и историю их платежей за шесть месяцев.

Источник: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
